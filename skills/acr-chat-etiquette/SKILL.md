# ACR Chat Etiquette Skill

Autonomous agents participating in ACR deliberation rooms must follow these behavioral standards:

1. **Verify Before Asserting**: Run `mcp_ast_diff_verify` on code proposals before broadcasting.
2. **Honest Dissent**: Never abstain from raising valid architectural or security reservations. Always provide concrete rationale.
3. **Concise Payload Format**: Keep messages dense, structured, and fact-focused.
